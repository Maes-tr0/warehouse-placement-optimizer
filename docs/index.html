JAVA · SPRING BOOT · ML

Intelligent warehouse placement and relocation optimizer.

A Spring Boot application that helps warehouse teams receive pallets, recommend storage places, analyze demand history, forecast article demand, and improve warehouse topology through relocation plans.

CAPABILITIES

Main features

Core modules implemented for warehouse setup, putaway and optimization.

  • 1Warehouse layout generationCreate aisles, rack rows, bays, levels and pallet storage places from a simplified template.
  • 2Operator putaway workflowReceive pallets, request placement recommendations, confirm placement and merge compatible containers.
  • 3Demand analytics and forecastingImport historical demand and train Java-based ML models for article demand prediction.
  • 4Optimization and relocationCalculate warehouse efficiency, create relocation plans and execute scan-validated relocation steps.

PROCESS

Application workflow

From warehouse setup to optimized relocation execution.

  • 1Admin creates warehouse and articlesThe system generates a usable warehouse topology and article catalog.
  • 2Operator receives and places palletsThe placement engine recommends a suitable location based on warehouse constraints.
  • 3Demand history improves decisionsImported order history is converted into analytics and demand forecast models.
  • 4Optimization creates relocation plansThe system identifies inefficient placement and guides operators through relocation steps.

DOCUMENTATION

Swagger / OpenAPI

When the application is running locally, the REST API is available through Swagger UI.

UI http://localhost:8080/swagger-ui.html
JSON http://localhost:8080/v3/api-docs

Use the Authorize button in Swagger UI and enter an existing application e-mail and password. Admin endpoints require ROOT_ADMIN or ADMIN; operator endpoints also allow OPERATOR.

This GitHub Pages site is a static project showcase. It does not host the Spring Boot backend. The local Swagger link works after running the application on your machine.
